## 📖 Introduction

Electromagnetic Induction Imaging (EMI) is a non-contact technique enabling the visualization of 
conductivity distributions by measuring magnetic fields generated by induced eddy currents.

This work leverages ultra-sensitive **Atomic Magnetometers (AMs)**, specifically 
**Radio-Frequency Atomic Magnetometers (RF-AMs)**, capable of detecting oscillating magnetic fields 
with exceptional sensitivity.

The study focuses on:

- RF-AM sensitivity and frequency response  
- Resonance linewidth optimization  
- Signal and image processing strategies  
- High-resolution EMI of conductive and weakly conductive materials  

---

## 🎯 Objectives

- Develop a **single-channel Rubidium RF-AM**
- Characterize sensitivity, linewidth, and operational bandwidth
- Demonstrate EMI imaging across a wide conductivity range
- Implement robust spectral and spatial data-processing pipelines

---

## 🔬 RF Atomic Magnetometer Performance

A compact **Rubidium RF-AM** was developed with:

- Operation near room temperature  
- Sensitivity: **55 fT / √Hz**  
- Resonance linewidth: **36 Hz**  
- Effective bandwidth: **kHz – MHz**  
- Reduced sensor volume → enhanced spatial resolution  

High-resolution EMI was successfully demonstrated for materials with conductivities spanning:

\[
6 \times 10^{7} \, \text{S/m} \rightarrow 500 \, \text{S/m}
\]

Typical sample volumes: few cm³  
Achieved spatial resolution: **~1 mm**

## ⚙️ Experimental Setup

The system is based on an **unshielded RF-AM architecture**, following:

Savukov *et al.*, *Phys. Rev. Lett.* **95**, 063004 (2005)

### Key Elements

- **Alkali vapor cell**: Rubidium (Rb)
- **Spin polarization**: Circularly polarized pump beam + DC bias field (**B<sub>BIAS</sub>**)
- **Frequency tuning**: Helmholtz coils (Zeeman tuning)
- **Calibration**: Controlled AC magnetic field
- **Detection**: Probe polarization rotation → polarimeter → lock-in amplifier

### Detection Chain

- **Polarimeter**  
  Polarizing beam splitter + balanced photodiode  
  *(Thorlabs PDB210A)*

- **Lock-in Amplifier (LIA)**  
  *(Ametek 7280 DSP)*

- **Spectrum Analyzer (SA)**  
  *(Anritsu MS2718B)*

## 🌀 Electromagnetic Induction Imaging Principle

- Primary RF magnetic field **B₁** induces eddy currents
- Eddy currents generate secondary magnetic field **B₂**
- Phase-sensitive detection reconstructs conductivity-related contrasts

EMI contrast depends on:

- Electrical conductivity  
- Magnetic permeability  
- Frequency / skin depth  
- Geometry

## 📐 Lorentzian Resonance Modeling

Magnetic resonance signals are modeled using absorptive and dispersive components:

**Absorptive (Lorentzian)**

$$ \tilde{S}_x (\omega_{RF}) =
\frac{S_0 B_{RF} \gamma \Gamma}
{4[(\omega_{RF} - \Omega_L)^2 + \Gamma^2 / 4]} $$

**Dispersive**

$$ \tilde{S}_y (\omega_{RF}) =
\frac{S_0 B_{RF} \gamma (\Omega_L - \omega_{RF})}
{2[(\omega_{RF} - \Omega_L)^2 + \Gamma^2 / 4]}$$

Where:

- \(\Gamma\) : linewidth  
- \(\Omega_L\) : Larmor frequency  
- \(\gamma\) : gyromagnetic ratio  

This decomposition enables:

- Precise resonance tracking  
- Noise-resilient phase estimation  
- Sensitivity optimization

## 🖼️ Image & Signal Processing

Implemented techniques:

1. **Gaussian filtering** → noise reduction  
2. **Convolution** → spatial smoothing  
3. **Cubic interpolation** → missing data recovery  
4. **Gradient removal** → scan artifact correction  
5. **Feature distance estimation**

## 🧪 Imaging Results — Copper Coin Example

The Lock-in Amplifier provides:

- **X** : In-phase (absorptive)  
- **Y** : Quadrature (dispersive)  
- **R = √(X² + Y²)** : Amplitude  
- **Φ = arctan(Y / X)** : Phase  

These outputs, combined with spectrum analyzer traces,
form the basis for:

- Resonance parameter extraction  
- Spatial EMI reconstruction  
- Eddy-current proxy mapping

## 🔁 Project Pipeline — Resonant Scan Processing & Eddy Current Mapping

This project processes frequency-scan measurements acquired on a 2D grid to reconstruct:

- Resonant parameter maps  
- Smoothed spatial images  
- Eddy-current density proxies  

### Pipeline Steps

1️⃣ **Per-pixel spectral fitting**  
Lorentzian + dispersive models (`lsqcurvefit`)

2️⃣ **Serpentine scan correction**  
Spatial reordering + Gaussian smoothing

3️⃣ **Optional metrology**  
Profile extraction + interpolation + extrema detection

4️⃣ **Eddy-current estimation**

\[
J(x,y) \approx \sigma B(x,y) \omega d
\]

⚠️ Qualitative model — see references for full EM diffusion physics.
